# Cleaner 2.1 — Public preview

A preview-first Windows cleaner with a clear interface and explicit control over privacy cleanup.

## Included
- Portable EXE launcher with custom icon and no console window.
- Dark, light and system themes; responsive navigation and cleanup review.
- Scoped temporary-file and browser-cache rules.
- Separate opt-in Chromium browsing-history cleanup.
- Explorer recent-list handling with pin checks.
- Local logs and readable source with sandbox tests.

## Get started
Download Cleaner-Portable.zip, extract the entire folder and run Cleaner.exe. Keep all companion files together. Windows 10/11 x64 with Windows PowerShell 5.1 is required.

## Before using this preview
- This release is unsigned and not independently audited.
- Cleanup permanently deletes selected data. Review candidates and back up valuable work.
- Browser storage formats vary. History removal is local; sync can restore activity.
- Forced app closing can lose unsaved work.
- The EXE launches the PowerShell application; it is not a self-contained native rewrite.

SHA256SUMS.txt contains the archive checksum. Please report reproducible issues with personal paths removed from logs and screenshots.
